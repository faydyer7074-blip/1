方法与使用顺序

  1. 录入同一配方的首末实测值和中间水干比，计算预测。
  2. 保存预测记录，再将中间点的实测值用于验证。
  3. 在“实测验证”打开记录或使用当前预测，粘贴两列数据。

首页采用两端幂律

η̂(r) = ηa (r/ra)−β
β = ln(ηa/ηb) / ln(rb/ra)

水干比 r = 加水质量 / 配料粉体质量。两端已知黏度决定曲线水平和下降斜率，配方组成在此方法中用于标识实验条件。

与 Ridge、K–D 的区别

Ridge 是未测目标料黏度时的历史数据预测；首页是已有首末实测后的区间预测；下方 K–D 为使用对应物性的独立计算。它们不是同一公式的变形。

怎样读误差

MAE 为平均绝对误差，RMSE 更重视较大误差，单位均为 Pa·s。n 为评分的不同中间配水位置数。已知端点不评分，同位置重复读数取均值。R² 在少于两点或实测值相同时不报告。

记录与隐私

计算、文件读取和导出在你的浏览器内完成。页面不提交你的配方、黏度或物性数据。保存文件需要你主动下载；刷新页面会清空未保存输入。

预测 JSON 含输入、条件和结果，可复算核对。其时间来自设备，不能单凭该文件证明中间实测此前未被查看。独立新批次结论需对应实验记录。

物性模型依据

K–D：η = ηl(1−φ/φm)−p。φ 由对应密度计算，φm来自独立浓度校准或堆积依据，首末黏度只用于估计 p。

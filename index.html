方法与使用顺序

  1. 输入同一配方的首末实测黏度和中间水干比，计算两端幂律。
  2. 有体积分数及堆积参数时，展开“物性分析”对照 K–D。
  3. 保存所选模型记录，用中间实测点检验。已知首末点不评分。

两端幂律

η̂(r) = ηa(r/ra)−β
β = ln(ηa/ηb) / ln(rb/ra)

r = 加水质量 / 配料粉体质量。首末实测决定曲线水平和稀释斜率。配方组成在此方法中用于记录条件。Ridge 则从历史配方、工艺和配水特征估计黏度，本站不运行 Python Ridge。

两端归一化 K–D

F = 1 − φ/φm，g = ηl(r)/ηl(ra)
η̂ = ηag(F/Fa)−p
p = [ln(ηa/ηb) + ln(gb)] / ln(Fb/Fa)

φ 为该位置的固相体积分数，φm 为有独立依据的最大堆积参数。先给定这些参数和液相比，再由首末实测求一个有效指数 p。液相黏度不变时 g = 1，绝对液相黏度约掉；仅同温度并不等于液相组成不变。若已知液相随配水变化，输入各点 g，首点为 1。

φ 可来自实测、文献方案或明确的假设情景，页面和导出文件保留其类型。名义干料体积分数需注明全干料不溶与体积可加条件；原料发生溶解时，该值与湿态真实固相不同。p/φm 是端点校准得到的有效特性黏数。

完整 K–D

η = ηl(1 − φ/φm)−p

输入对应密度、气体处理、液相黏度及 φm，单独拟合 p。这个版本不强制穿过两个端点。两种 K–D 图线都只连接已输入物性的计算位置。

公式依据

K–D 原式见以下文献；两端归一化为本工具对原式取比值、取对数的代数推导。两端幂律是本研究的经验标定基线。
